# GitHub publishing checklist

1. Confirm the repository folder contains the Python files, `README.md`, `requirements.txt`, `.gitignore`, compact `results/` summaries, and `data/README.md`.
2. Do not upload raw user or third-party files (`data/*.csv`, `.rg`, `.rss`, `.sp3`, full GEDVM archives, or `input_2023_w01.csv`) without checking permissions.
3. Check for passwords, local absolute paths, personal files and data licenses before publishing.
4. Create a new GitHub repository and upload the unzipped contents of this folder, preserving subdirectories. The ZIP is an export format, not the desired repository content.
5. Verify at least three key scripts and the `README.md` display correctly on GitHub.
6. Copy the repository's URL and insert it into Appendix C.5 of the final manuscript. Compile the PDF and verify its eight main-text pages.
7. Check the coursework requirements for how AI/code assistance should be acknowledged.
